# API 보안 실험 (SEC)

| ID | 시나리오 | 재현 조건 | 기대값 | 측정 |
| --- | --- | --- | --- | --- |
| SEC-01 | BOLA/IDOR | 사용자 A가 B의 비공개 문서 ID 조회 | 403 | 무단 조회 성공 0건 |
| SEC-02 | 역할 우회 | 일반 사용자가 관리 API 호출 | 403 | 관리자 기능 오남용 0건 |
| SEC-03 | 로그인 반복 | 실습 계정 비밀번호 반복 오입력 | 일시 제한, 기록 | 제한 도달 시간, 오탐 |
| SEC-04 | 과도한 호출 | 정해진 윈도우를 넘는 API 요청 | 429 | 차단 비율, 지연 증가 |

## 구조

```text
api-security/
├─ vulnerable-api/   # ⚠️ 인가 검사를 뺀 대조군 앱 (127.0.0.1:18080, 루프백 전용)
├─ runner/           # 같은 공격을 두 대상에 실행하는 시나리오 러너 (JDK만 사용)
└─ results/          # 실행 요약 (raw/ 는 Git 제외)
```

- 대상은 `127.0.0.1` 또는 Docker 내부 네트워크뿐이다.
- 같은 시나리오를 `vulnerable-api`(취약)와 `backend`(보호)에 각각 실행해 비교한다.
- SEC-03/04는 4주차(요청 제한·로그인 탐지) 이후 러너에 추가한다.
