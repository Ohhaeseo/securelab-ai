# SEC-01/02 실측 결과 (20261121-004018)

- 시도: 대상별 30회 (워밍업 3회 제외), 시도마다 새 사용자 2명
- 대상: `protected` http://127.0.0.1:18081  `vulnerable` http://127.0.0.1:18080  
- 런타임: Java 21.0.8, Windows 11, CPU 코어 8
- 판정: 공격은 **실제로 보안 목표가 침해됐는지**(본문 노출, 목록 노출, 변경 반영, 삭제 반영, 관리자 응답 수신)로 센다. 응답 코드만 보지 않는다.
